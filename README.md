# zen-site

A fast static site generator. Given a site description (Markdown sources,
templates, and static files), it produces exactly the output tree that
`makefun-site` 1.0.0 produces: each page's `index.html`, the paginated index,
tag pages, `build-report.txt`, and every static file — byte for byte.

## Layout

- `solve.js` — the solver. `run(input)` returns the output tree for one case;
  `runBatch(inputPath, outputPath)` answers every case in a cases file.
- `main.ts` — the driver. Reads every case from the input cases file and
  writes the answers file.
- `native.js` — loads the native addon (`zen.node`) and falls back to a
  pure-JavaScript slugifier if the native Unicode table does not match the
  running Node's Unicode version.
- `native/` — the native core (C++17, N-API 8):
  - `addon.cc` — the N-API module: `runJson`, `runBatch`, `slug`,
    `unicodeVersion`.
  - `zen_core.hpp` — arena allocator, JSON parser/serialiser, JavaScript
    string and whitespace semantics, HTML/JSON escaping (SIMD), slug rules.
  - `zen_md.hpp` — the Markdown subset renderer.
  - `zen_tpl.hpp` — front-matter parser and the template dialect
    (variables, loops, conditionals, includes with an absolute depth budget).
  - `zen_site.hpp` — the site pipeline: sources, permalinks, collections,
    tags, layouts, report.
  - `unicode.hpp` — the NFKD slug table for Unicode 17.0, generated by
    `tools/gen_unicode.mjs`.
- `tools/` — `build.mjs` (build the addon), `gen_unicode.mjs` (regenerate the
  Unicode table), `verify.mjs` (differential tests against the oracle, edge
  cases, determinism), `bench.py` (cold-process CPU benchmark).

## How to run

The addon ships prebuilt as `zen.node`, so no compiler is needed at run time.

```sh
# answer the practice cases
MAKEFUN_INPUT_DIR=path/to/input MAKEFUN_OUTPUT_DIR=path/to/output node main.ts

# or, from JavaScript
import { run } from "./solve.js";
const output = run(input);
```

To rebuild the addon (needs g++ and the Node 22.23.4 headers):

```sh
node tools/build.mjs          # normal build
node tools/build.mjs --pgo    # profile-guided build (falls back if it fails)
```

## Correctness notes

- Output is deterministic: the same input always yields the same output.
- The template dialect, Markdown subset, slug rule, and report format follow
  the `makefun-site` 1.0.0 reference exactly, including its error strings.
- Includes have an absolute depth budget (cyclic includes terminate the way
  the reference does). Word counts use JavaScript whitespace semantics
  (Unicode NBSP is a word separator). Template lookups use own properties
  only, with loop scopes shadowing outer names.
